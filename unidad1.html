Bienvenidos para aprender HTML

Es la estructura base y obligatoria de cualquier página web en HTML. Funciona como el esqueleto del documento y se divide en dos partes principales:

  • <head> (Cabecera): Configura los datos invisibles de la página, como el idioma, la codificación para que se lean bien los acentos y el título que aparece en la pestaña del navegador.
  • <body> (Cuerpo): Contiene todo lo visible para el usuario (textos, imágenes, botones), que en este ejemplo muestra un título de nivel seis (<h6>).

Puedes poner todo este solo guardando el documento como html y ya que lo tengas guardado le pones !+enter y ya sale todo esto ya solo empezaras a escribir tu codigo.

Las letras h vienen de la palabra en inglés "heading", que significa encabezado o título. Se utilizan para estructurar el contenido de una página web por orden de importancia, dividiéndose en seis niveles diferentes: desde el título principal h1 hasta el subnivel más pequeño h6.

Etiqueta p y br

La etiqueta p se utiliza para escribir párrafos de texto dentro de una página web. Crea un párrafo nuevo y deja un espacio entre un párrafo y otro.

La etiqueta br hace un salto de línea dentro del mismo párrafo, sin dejar espacio adicional.

Etiqueta para tipos de letras (b,i,u,small,mark,del,subdindice,superindice)

HTML ofrece diferentes etiquetas para cambiar el estilo del texto. Con ellas es posible escribir en negrita, cursiva, subrayado, resaltar palabras, reducir el tamaño del texto, tachar contenido y agregar subíndices o superíndices. Estas etiquetas permiten organizar mejor la información y hacer que el contenido sea más llamativo y fácil de leer.

Etiqueta (li) Listas ordenadas (ol) y desordenadas (ul)

La etiqueta li se utiliza para representar cada elemento o punto dentro de una lista.
Esta etiqueta siempre debe colocarse dentro de una lista ordenada (ol) o una lista no ordenada (ul).
Cada vez que se agrega una etiqueta li, se crea un nuevo elemento dentro de la lista,
permitiendo organizar la información de forma clara, ordenada y fácil de leer.

Etiqueta A (Enlaces)

La etiqueta a se utiliza para crear enlaces o vínculos que permiten navegar de una página a otra,
abrir un sitio web, descargar archivos o dirigirse a una sección específica de la misma página.
El atributo href indica la dirección o URL a la que se desea acceder cuando el usuario hace clic en el enlace.
Es una de las etiquetas más importantes de HTML, ya que hace posible la conexión entre diferentes páginas web

Etiqueta img (Imagenes)

La etiqueta img utiliza varios atributos para controlar cómo se muestra una imagen.

  • src: Indica la ubicación o ruta de la imagen.
  • img/ Es la carpeta donde está guardada la imagen.
  • flor.png Es el nombre del archivo de la imagen.
  • alt: Muestra un texto alternativo si la imagen no puede cargarse.
  • width: Define el ancho de la imagen.
  • height: Define la altura de la imagen.

Etiquetas de Video y Audio

Para insertar y reproducir archivos multimedia en una página web, HTML cuenta con etiquetas nativas muy sencillas de utilizar:

  • Audio (<audio>): Funciona de manera muy similar al video, creando un reproductor de sonido compacto para archivos de música o voz.

Mapa de imagen

Las siguientes etiquetas y atributos se utilizan para crear un mapa de imagen en HTML, permitiendo que diferentes zonas de una imagen funcionen como enlaces.
https://www.image-map.net/ puedes usar esta pagina para que obtengas con exactitud que coordenadas son las que necesitas para tu mapa de imagen.

  • <map>: Crea un mapa de imagen que permite definir varias áreas clicables dentro de una misma imagen.
  • name="workmap": Asigna un nombre al mapa de imagen. Este nombre se utiliza para relacionar el mapa con la imagen mediante el atributo usemap.
  • <area>: Define una zona o área específica dentro de la imagen que podrá recibir clics.
  • shape="rect": Indica que el área tendrá forma de rectángulo. También existen otras formas como circle (círculo) y poly (polígono) default(Toda la imagen)
  • coords="16,23,279,118": Especifica las coordenadas que delimitan el área clicable dentro de la imagen. Estas coordenadas indican la posición y el tamaño del rectángulo.
  • alt="Rectangulo": Proporciona un texto alternativo que describe el área. Este texto se muestra si la imagen no puede cargarse y también mejora la accesibilidad.
  • href="rectangulo.html": Indica la página web o archivo que se abrirá cuando el usuario haga clic sobre esa área de la imagen.

Tablas de html

Las tablas en HTML se crean utilizando la etiqueta table, que define la estructura de la tabla. Dentro de esta etiqueta, se utilizan otras etiquetas para organizar el contenido:

Etiquetas principales para crear tablas

Etiqueta Descripción
<table> Define el inicio y el final de una tabla.
<tr> Crea una fila dentro de la tabla.
<th> Define una celda de encabezado. Generalmente aparece en negritas y centrada.
<td> Define una celda de datos.
border Agrega un borde alrededor de la tabla y sus celdas.
rowspan Une dos o más filas en una sola celda.
colspan Une dos o más columnas en una sola celda.
