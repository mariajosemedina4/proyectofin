1. Qué es CSS

CSS (Cascading Style Sheets, Hojas de Estilo en Cascada) sirve para controlar la apariencia de una página: color, fuente, tamaño del texto, espacio entre elementos, cómo se acomodan en la pantalla, fondos, y hasta cómo se ve en distintos tamaños de pantalla. Se llama "en cascada" porque el estilo que se le aplica a un elemento padre también se aplica a sus elementos hijos, a menos que se indique algo diferente.

Formas de usar CSS

  • En línea (inline): con el atributo style dentro de la etiqueta.
  • Interno (internal): con la etiqueta <style> dentro del <head>.
  • Externo (external): con <link> apuntando a un archivo .css aparte.

Border, padding y margin

border pone un borde alrededor del elemento, padding es el espacio entre el contenido y el borde, y margin es el espacio que separa al elemento de los demás elementos de la página.

Este párrafo tiene border, padding y margin aplicados para que se note la diferencia.

2. Atributos

Los atributos dan información adicional sobre una etiqueta. Se ponen dentro del tag de apertura y casi siempre vienen en pares nombre="valor".

  • src: indica la ruta de una imagen o archivo.
  • href: indica a dónde lleva un enlace.
  • alt: texto alternativo que se muestra si la imagen no carga.
  • width / height: ancho y alto de un elemento.
  • style: agrega estilo directo al elemento (color, fuente, tamaño, etc.).

En el atributo src de una imagen se puede usar una URL absoluta (la dirección completa de una imagen que está en otro sitio) o una URL relativa (la ruta del archivo dentro del mismo proyecto, sin el dominio).

3. El atributo style

El atributo style se usa para dar formato a un elemento específico: color de texto, color de fondo, tipografía, tamaño y alineación.

color:red;

background-color:powderblue;

font-family:verdana;

font-size:160%;

text-align:center;

text-align:right;

4. Colores

En CSS los colores se pueden escribir de varias formas: por nombre, en RGB, en hexadecimal (HEX), en HSL, y sus versiones con transparencia RGBA y HSLA.

FormatoEjemploResultado
NombreTomatoTomato
RGBrgb(255,99,71)rgb
HEX#ff6347hex
HSLhsl(9,100%,64%)hsl
RGBArgba(255,99,71,0.5)rgba
HSLAhsla(9,100%,64%,0.5)hsla

En RGB, cada valor de rojo, verde y azul va de 0 a 255. (255,0,0) es rojo puro, (0,0,0) es negro y (255,255,255) es blanco. Cuando los tres valores son iguales se obtiene una tonalidad de gris.

En HSL el primer número es el matiz (0 a 360, un grado en la rueda de color), el segundo es la saturación (0% sin color, 100% color puro) y el tercero es la luz (0% negro, 100% blanco).

RGBA y HSLA agregan un cuarto valor, el canal alpha, que va de 0 (transparente) a 1 (sin transparencia).

El color también se puede aplicar al texto o al borde:

color:DodgerBlue;

border:2px solid Violet;

6. Imágenes

La etiqueta img no inserta la imagen dentro del HTML, solo la enlaza: crea un espacio donde se mostrará la imagen. Es una etiqueta vacía (no tiene cierre) y necesita al menos src y alt.

  • width / height: tamaño de la imagen, ya sea como atributo o dentro de style.
  • float: hace que el texto rodee la imagen, a la izquierda o a la derecha.
  • background-image: pone una imagen como fondo de cualquier elemento, incluyendo el body.
  • Imagen como link: se logra poniendo la etiqueta img dentro de una etiqueta a.
  • map / area: crean un mapa de imagen, donde distintas zonas de una misma imagen son enlaces diferentes.

7. Listas

Lista desordenada (ul)

Cada elemento se marca con li. Con list-style-type se cambia el marcador.

  • Coffee
  • Tea
  • Milk
  • Coffee
  • Tea
  • Milk

Lista ordenada (ol)

Se numera por default. El atributo type cambia el marcador: 1 números, A mayúsculas, a minúsculas, I romanos, i romanos minúscula.

  1. Coffee
  2. Tea
  3. Milk
  1. Coffee
  2. Tea
  3. Milk

Lista descriptiva (dl)

dt es el término y dd su descripción.

Coffee
- bebida caliente y oscura
Milk
- bebida blanca y fría

8. Tablas

Las tablas organizan datos en filas y columnas. tr es una fila, td es una celda de datos y th es una celda de encabezado.

Firstname Lastname Age
Jill Smith 50
Eve Jackson 94

Bordes en tablas

Con border se agregan bordes a la tabla, th y td. Con border-collapse:collapse se evita el doble borde entre celdas. Con border-style se cambia su forma (dotted, dashed, solid, double, groove, ridge, inset, outset). Con border-radius se redondean las esquinas y con border-color se le da color al borde.
