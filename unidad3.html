¿Qué es JavaScript?

JavaScript es un lenguaje de programación interpretado que permite agregar interactividad a las páginas web. Gracias a él es posible crear botones, formularios dinámicos, animaciones, juegos, validaciones, calculadoras, aplicaciones web completas y mucho más.

Actualmente es uno de los lenguajes más utilizados del mundo y forma parte fundamental del desarrollo Front-End junto con HTML y CSS.

¿Por qué aprender JavaScript?

  • ✔ Es fácil comenzar.
  • ✔ Tiene mucha demanda laboral.
  • ✔ Funciona en todos los navegadores.
  • ✔ Permite crear sitios dinámicos.
  • ✔ También puede usarse en el servidor con Node.js.

Historia de JavaScript

JavaScript nació para hacer que las páginas web dejaran de ser estáticas. Con el paso de los años evolucionó hasta convertirse en uno de los lenguajes de programación más importantes del mundo.

1995

Creación

Brendan Eich desarrolló JavaScript en solo 10 días mientras trabajaba para Netscape.

1997

ECMAScript

JavaScript se convirtió en un estándar internacional bajo el nombre de ECMAScript.

2009

Node.js

Aparece Node.js, permitiendo ejecutar JavaScript fuera del navegador.

Actualidad

Lenguaje líder

Hoy JavaScript se utiliza para crear sitios web, aplicaciones móviles, videojuegos y servidores.

¿Cómo funciona JavaScript?

Cuando una página web se carga en el navegador, HTML crea la estructura, CSS agrega el diseño y JavaScript se encarga del comportamiento.

Gracias a JavaScript podemos detectar clics, modificar texto, cambiar imágenes, realizar cálculos y comunicarnos con servidores sin recargar la página.

Las tres tecnologías principales del Desarrollo Web

Para crear una página web moderna se utilizan tres tecnologías que trabajan en conjunto.

HTML

Es el lenguaje encargado de crear la estructura de una página web. Define títulos, párrafos, imágenes, tablas, formularios y todos los elementos que aparecen en pantalla.

CSS

Se utiliza para diseñar la apariencia del sitio web. Permite cambiar colores, tamaños, posiciones, animaciones y adaptar la página a diferentes dispositivos.

JavaScript

Agrega la interactividad. Hace posible crear calculadoras, formularios dinámicos, juegos, validaciones, menús, animaciones y aplicaciones completas.
