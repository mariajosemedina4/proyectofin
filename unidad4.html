¿Cómo Nació PHP?

Fue creado originalmente por Rasmus Lerdorf en 1994. En aquel entonces, Lerdorf era un reconocido programador danés-canadiense. La mascota de PHP es un elefante y fue diseñada por Vincent Pointier en 1998. Si se le añade un contorno, se puede apreciar la idea que inspiró el logotipo de PHP. Con el tiempo, se crearon muchas variaciones de esta mascota, pero finalmente se adoptó la versión original.

¿Qué es PHP?

PHP (Hypertext Preprocessor) es un lenguaje de programación de código abierto diseñado principalmente para el desarrollo web y es utilizado en el 77% de proyectos de software.

Propósito

PHP fue creado específicamente para desarrollar páginas web

Características

Variables en PHP

String

¿Qué es?

string (o cadena de caracteres) en PHP es un tipo de dato fundamental que sirve para almacenar texto, el cual se escribe siempre entre comillas simples o dobles.

Ejemplo:

$nombre = "Juan";
$apellido = 'Pérez';

Resultado:
Juan Pérez

Integer

¿Qué es?

Un integer (o entero) en PHP es un número sin decimales que pertenece al conjunto de los números enteros, pudiendo ser positivo, negativo o cero. Los detalles clave incluyen el uso de bases numéricas (como decimal, hexadecimal u octal) y límites de tamaño dependientes del sistema operativo.

Ejemplo:

$edad = 25;
$numero = -10;

Resultado:
24
-10

Float

¿Qué es?

Un float en PHP es un tipo de dato que representa números con decimales o números en coma flotante, y también admite notación científica. Almacena valores reales con una precisión máxima de unos 14 dígitos. Su tamaño depende del equipo o sistema operativo, llegando por lo general hasta un valor cercano a 1.8 × 10³⁰⁸. Los decimales siempre se separan usando un punto (.) y no una coma.

Ejemplo:

$precio = 19.99;
$temperatura = -5.5;

Resultado:
19.99
-5.5

Boolean

¿Qué es?

Un boolean (o booleano) en PHP es un tipo de dato lógico que solo puede tener dos valores: true (verdadero) o false (falso). Se usa principalmente para tomar decisiones en el código mediante condiciones.

Ejemplo:

$activo = true;
$eliminado = false;

Resultado:
1 (si se imprime true)
(no muestra nada si se imprime false)

Array

¿Qué es?

Un array en PHP es una variable especial que guarda múltiples valores en una sola estructura. Los tres tipos principales de arrays son indexados, asociativos y multidimensionales.

Ejemplo:

$colores = ["rojo", "azul"];
$datos = array("nombre"=>"Ana");

Resultado:
Array
(
[0] => rojo
[1] => azul
)
Array
(
[nombre] => Ana
)

Null

¿Qué es?

En PHP, null es un tipo de datos especial que representa una variable sin valor. Una variable se considera null si se le asigna explícitamente la constante null, si no se le ha asignado ningún valor todavía, o si se ha borrado usando la función unset().

Ejemplo:

$variable = null;

Resultado:
(no muestra nada en pantalla)

Ejemplo práctico de variables

<?php
$nombre = "María";
$edad = 30;
$altura = 1.65;
$es_estudiante = true;
$hobbies = ["leer", "nadar", "viajar"];

echo "Mi nombre es $nombre y tengo $edad años";
echo "Mido $altura metros";
echo "¿Es estudiante? " . ($es_estudiante ? "Sí" : "No");
echo "Mis hobbies: " . implode(", ", $hobbies);
?>

Resultado:
Mi nombre es María y tengo 30 años
Mido 1.65 metros
¿Es estudiante? Sí
Mis hobbies: leer, nadar, viajar

Condicionales

If - Else

<?php
$edad = 18;

if ($edad >= 18) {
    echo "Eres mayor de edad";
} else {
    echo "Eres menor de edad";
}
?>
Explicación del código:
  • Evaluación de condición: El código verifica el valor de la variable $edad. En este caso, la variable tiene el valor 18.
  • Condición if: Se ejecuta if ($edad >= 18). Al ser la edad igual a 18, la condición es verdadera. Por lo tanto, el programa entra en este bloque.
  • Bloque else: El bloque else solo se ejecutaría si la condición anterior fuera falsa. Como la condición fue verdadera, este bloque se omite.
  • Salida final: Se imprime en pantalla el texto "Eres mayor de edad".

Else If

<?php
$nota = 85;

if ($nota >= 90) {
    echo "Excelente";
} elseif ($nota >= 70) {
    echo "Aprobado";
} else {
    echo "Reprobado";
}
?>
Explicación del código:
  • Evaluación inicial: El programa analiza la variable $nota, cuyo valor es 85.
  • Primera condición (if): Comprueba $nota >= 90. Como 85 no es mayor o igual a 90, esta condición es falsa y el bloque se omite.
  • Segunda condición (elseif): Al fallar la primera, evalúa $nota >= 70. Como 85 sí es mayor o igual a 70, esta condición es verdadera. El programa entra en este bloque.
  • Bloque else: El bloque else es la opción por defecto. Solo se ejecutaría si todas las condiciones anteriores (if y elseif) fueran falsas.
  • Salida final: Como entró en el segundo bloque, se imprime el texto "Aprobado".

Switch

<?php
$dia = "lunes";

switch($dia) {
    case "lunes":
        echo "Inicio de semana";
        break;
    case "viernes":
        echo "Fin de semana";
        break;
    default:
        echo "Otro día";
}
?>
Explicación del código:
  • Variable a evaluar: El código toma la variable $dia con el valor "lunes".
  • Estructura switch: Evalúa la variable contra múltiples casos (case). Es una alternativa más limpia a múltiples bloques elseif cuando se comparan valores específicos.
  • Coincidencia de caso: El programa compara el valor de la variable con el primer caso: case "lunes". Como coincide exactamente, ejecuta el código de ese bloque.
  • Instrucción break: La palabra clave break; es fundamental. Detiene la ejecución del switch para que no siga evaluando los casos siguientes de manera accidental.
  • Bloque default: Es la opción final. Solo se ejecuta si ninguno de los case anteriores coinciden.
  • Salida final: Se imprime en pantalla el texto "Inicio de semana".

Operador Ternario

<?php
$edad = 20;
$mensaje = ($edad >= 18) ? "Mayor" : "Menor";
echo $mensaje;
?>
Explicación del código:
  • Sintaxis compacta: El operador ternario es una forma resumida de escribir un bloque if-else en una sola línea. Su estructura es: (condición) ? (valor si es verdadero) : (valor si es falso).
  • Evaluación de condición: El código evalúa ($edad >= 18). Como la variable $edad es 20, la condición es verdadera.
  • Asignación de valor: Al ser verdadera, el operador retorna el primer valor ("Mayor"). Este valor se asigna inmediatamente a la variable $mensaje.
  • Alternativa falsa: Si la condición hubiera sido falsa, el operador habría retornado el segundo valor ("Menor").
  • Salida final: Se imprime en pantalla el valor de $mensaje, que es "Mayor".

Ejemplos Prácticos

Ejemplo 1: Calculadora

<?php
function sumar($a, $b) {
    return $a + $b;
}

$resultado = sumar(5, 3);
echo "5 + 3 = $resultado";
?>
Resultado:
8


Ejemplo: Recorrer Array

<?php
$frutas = ["Manzana", "Banana", "Naranja"];

foreach($frutas as $fruta) {
    echo "Fruta: $fruta <br>";
}
?>
Resultado:
Manzana, Banana, Naranja
